# Demo script

A script for the 2-minute demo video. The outline below is fixed; exact clicks and timings are written in phase 6, once every surface exists.

## Setup

- Laptop 1: `/eye` open with the webcam, in demo mode.
- Laptop 2 or a second window: `/command`.
- Phone: `/guard`, with a guard picked and "Start shift" tapped so sound is unlocked.

## Outline

1. **The problem.** In danger, a phone and a voice are the first things an attacker controls.
2. **The signal.** Palm open with the thumb tucked in, then fingers folded over the thumb.
3. **Live flow.** Make the signal at the camera. The dashboard shows the alert on the map. The first guard is rung and does not answer; the second taps "I'm going"; the dashboard shows who is responding with a running timer. Resolve the alert.
4. **Trust.** No video recorded, no faces identified, one snapshot only, and a person always decides.
5. **Close.** No app. No phone. No words. Just a hand.
